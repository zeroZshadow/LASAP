# the file menu to a level, a death dropped on the intro, the title and the file menu (no save is loaded there), then
# file 1 loads with Link alive.
connect 90
screen intro 5
game DEATH Tester

game DEATH Tester

screen menu 5
game DEATH Tester
expect DEATHDROPPED 5
tapuntil 1 files:DataSelectConfirm when files:DataSelectKeyWait

screen loading|level 10
screen level 30
