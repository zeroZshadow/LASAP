# From a fresh boot: skip the intro, open the file menu, load file 1 (a played file: the user's, or the one in the
# new-game snapshot). Each press waits until the screen takes it (TESTING.md, "Game state") and stops the script
# within seconds when it is not taken.
connect 90
# The intro ends on a button once the title exists; the title takes L+R in WaitLR.
tapuntil 1 screen=title when title:Deactive 30
tapuntil c0 title:GameStart when title:WaitLR+unlocked 20
# The cursor starts on the last file used; file 1 is slot 0. A opens it, A again starts it.
select 0
tapuntil 1 files:DataSelectConfirm when files:DataSelectKeyWait
tapuntil 1 files:GameStart when files:DataSelectConfirm
loaded 60
