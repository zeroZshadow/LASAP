# Warp home with BowWow following. Sets what rescuing him sets (companion bit 0 of inventory byte 0x9d, as LASR
# uses it, and BowWowJoin), reloads Mabe so he spawns, warps home with the menu and walks back out the door. Clears
# both at the end, so later scripts walk alone. Screenshots: bowwow_1 Mabe, bowwow_2 Tarin's house, bowwow_3 outside
# again.
send DBG setflag BowWowJoin 1
expect FLAG.BowWowJoin.1 5
send DBG poke 9d 01
expect OK.poke 5
warp Field 38.25 10.5 128.25
# The screenshot waits for BowWow to come running.
wait 2
shot D:/DEV/LASAP-sandbox/bowwow_1.png
hold 800 0 0 until !event=0 5
until msg:Selecting 10
choose 0
inlevel 20
level MarinTarinHouse
loaded 20
shot D:/DEV/LASAP-sandbox/bowwow_2.png
hold 0 0 -32767 until level=Field 5
inlevel 20
level Field
loaded 20
shot D:/DEV/LASAP-sandbox/bowwow_3.png
state
send DBG setflag BowWowJoin 0
expect FLAG.BowWowJoin.0 5
send DBG poke 9d 00
expect OK.poke 5
