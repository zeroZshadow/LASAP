# Instant Pickups and the buffs: the first Guardian Acorn in a new game, whose pickup plays an item-get with its text,
# gives the buff at once: no text, its music (BGM_NUTS_INTRO) starts, no popup. Run after newgame_file2 on a mod
# patched with Instant Pickups. The drop is forced as in buff_drops (KillCountNoDamage, inventory a5, one short of
# 14), then Link walks onto it.
guard msg:Reading
send DBG grant SwordLv1 1 -1 0
expect OK.grant 5
send DBG poke a4 000d
expect OK.poke 5
guard hurt
send DBG press 0 2 0 -32767 0 when free+level=Field 40000
send DBG press 2 60 2 when face=left 5000
warp Field 42.75 9.0 147.75
poll PEEK\si\sa4\s01(00|0e) 5 DBG peek i a4 2
guard off hurt
# The hit knocks the Octorok west before it dies, so the acorn lies under the wall, about two tiles west of where the
# Octorok stood; Link walks up to the wall and along it.
send DBG input 0 3000 -20000 20000
expect OK.input 5
await 4 \sbgm=\S*BGM_NUTS_INTRO
check popup=0
check msg=Closed
guard off msg:Reading
