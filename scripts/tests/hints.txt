# In-game hints (DESIGN.md, In-game hints): reading an owl statue or a library book shows its hint, sets its flag,
# and the client makes it a server hint. Run after newgame_file2 with the client connected to the server, on a seed
# with In-Game Hints server, Owl Statues all and dungeon items in their own dungeon (no stone beaks at the start).
# Flags: APHint4 Martha's Bay owl, APHint30 and APHint31 Color Dungeon 06C and 07D owls, APHint33 the shield book.
# Screenshots: hint_owl, hint_book, hint_nobeak, hint_dungeon, each once the text waits for a button.
# Martha's Bay owl (no beak needed): the hint, then its Owl Gift.
warp Field 156.75 7.5 162.75
face up
interact
until textready 10
shot hint_owl.png
dismiss 30
send DBG flag APHint4
expect FLAG.APHint4.1
logged \[Hint\] 20 server 1
# The library's shield book: A, then Yes.
warp Library 12.76 0 5.74
face up
interact
until msg:Selecting 10
choose 0
until textready 10
shot hint_book.png
dismiss 30
send DBG flag APHint33
expect FLAG.APHint33.1
logged \[Hint\] 20 server 2
# Color Dungeon 06C (its three statues shared one entry point; the rooms have no enemies): without the beak it says
# nothing new.
warp Lv10ClothesDungeon 35.25 0 62.25
face up
interact
until textready 10
shot hint_nobeak.png
dismiss 30
send DBG flag APHint30
expect FLAG.APHint30.0
# With the Color Dungeon's beak: the hint, then its Owl Gift.
send DBG grant StoneBeak 1 9 0
expect OK.grant 5
goto 35.25 0 62.25
face up
interact
until textready 10
shot hint_dungeon.png
dismiss 30
send DBG flag APHint30
expect FLAG.APHint30.1
logged \[Hint\] 20 server 3
# A hint read while the server is away (Color Dungeon 07D) reaches it on the next connection.
send /disconnect
until server=0 10
warp Lv10ClothesDungeon 53.25 0 74.25
face up
interact
until textready 10
dismiss 30
send DBG flag APHint31
expect FLAG.APHint31.1
send /connect
logged \[Hint\] 30 server 4
state
